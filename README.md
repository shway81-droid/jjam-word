# 짬짬이 낱말

> **문제 하나로 반 전체의 입을 연다. 교사는 딸깍 세 번이면 된다.**

수업 전후 3~7분 자투리 시간에, 전자칠판에 말놀이 문제 하나를 화면 가득 띄우고
반 전체가 **보기 없이 입으로** 답을 외치는 웹서비스입니다. 설치·로그인 없음.

👉 **[짬짬이 낱말 열기](https://shway81-droid.github.io/jjam-word/)**

## 이런 시간에 씁니다

- 수업 시작 전, 아이들이 아직 들떠 있을 때
- 진도를 마치고 3분이 남았을 때
- 급식 전 줄 서기 직전

## 말놀이 6종

**문제 내기** — 문제 → 힌트 → 정답, 딸깍 최대 3번

| | | |
|---|---|---|
| 🔤 **ㄱㄴㄷ 초성퀴즈** | 초성을 보고 낱말을 외쳐요 | 120문항 · 주제 8종 |
| 🗣 **속담 이어말하기** | 앞부분을 보고 뒷부분을 외쳐요 | 100문항 |
| 🀄 **사자성어** | 뜻을 보고 사자성어를 외쳐요 | 90문항 |
| ❓ **수수께끼** | 수수께끼의 답을 외쳐요 | 90문항 |

**진행 도우미** — 정답 데이터 없이 진행만 맡는 화면

| | | |
|---|---|---|
| 🔗 **끝말잇기 도우미** | 시작 단어 · 모둠 차례 · 제한 시간 · 지나간 차례 기록 | 시작 단어 60개 |
| 🎭 **몸으로 말해요** | 단어 카드를 화면 가득 (한 명만 등지고 맞히기) | 카드 100장 |

난이도는 **쉬움 · 보통 · 어려움** 3단계. 학년이 아니라 난이도인 이유는, 같은 반에서도
쉬운 문항으로 몸을 풀고 어려운 문항으로 넘어가는 운영이 가능해야 하기 때문입니다.

## 교탁에서

| 키 | 하는 일 |
|---|---|
| `Space` | 다음 단계 (문제 → 정답 → 다음 문제) |
| `H` | 힌트 열기 (한글 자판의 `ㅗ` 도 됩니다) |
| `Esc` | 마치기 |

리모컨·무선 키보드로 진행할 수 있습니다. 힌트는 건너뛸 수 있어, 아이들이 바로
맞히면 딸깍 두 번으로 다음 문제로 갑니다.

## 이런 점을 신경 썼습니다

- **보기가 없습니다.** 고르는 활동이 아니라 입을 여는 말놀이입니다. 답이 여러 개여도 됩니다
- **자동 진행이 없습니다.** 외침을 기다려야 하므로 모든 전환은 선생님 조작으로만
- **최근 낸 문항은 다시 나오지 않습니다** (유형별 50개, 새로고침해도 유지)
- **오프라인에서 됩니다.** 한 번 열어 두면 인터넷이 끊겨도 계속 문제가 나옵니다
- **소리를 꺼도 전부 됩니다.** 효과음은 보조입니다
- 비속어·차별 표현, 특정 학생이 상처받을 소재, 정치·종교 소재를 넣지 않았습니다.
  속담·사자성어 원문에 낡은 표현이 있으면 그 문항을 아예 뺐습니다

## 개발

```bash
npm install
npm start          # http://localhost:8379
npm test           # 순수 로직 테스트 + 데이터 검증 + 폰트 커버리지
npm run sync:check # 상류(jjam)와 공통 파일 일치 확인
npm run icons      # favicon.svg → 앱 아이콘 PNG
```

문항을 추가할 때는 `data/words.json` 에만 넣으면 됩니다. 스키마·중복·안전 기준·
난이도 분포는 `npm test` 가 검사합니다. 자세한 규칙은 `CLAUDE.md`,
요구사항 원본은 `짬짬이_낱말_PRD.md` 를 보세요.
